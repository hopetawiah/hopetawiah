## 🚀 Featured Project

### 🏫 Dunamis Crown Academy School ERP

A production **School Enterprise Resource Planning and Management Information System** designed and developed for Dunamis Crown Academy, Ghana.

The system integrates academic management, finance, communications, analytics, cybersecurity controls, reporting, backup/recovery, and secure administration.

**Selected security and engineering features:**

* Role-Based Access Control (RBAC)
* Granular role permission matrix
* TOTP two-factor authentication
* Account lockout and login-history monitoring
* CSRF protection
* Request rate limiting
* Security-sensitive audit logging
* PostgreSQL database
* SHA-256 backup integrity validation
* Secure session and cookie controls
* HTTP security headers
* AI-assisted decision-support analytics
* PDF and Excel reporting
* SMS integration
* Docker and Render deployment
